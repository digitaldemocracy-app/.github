# Digital Democracy

**Organizing the world's democracy.** An open, global platform for constructive debate, voting and democratic participation — built in public, from the first line of code.

- 📜 **[Manifesto](https://github.com/digitaldemocracy-app/manifesto)** — read it in ten languages, disagree, propose, sign.
- 📚 **Docs** — product vision, requirements, architecture decisions and the public roadmap. Opening soon.
- 🛠️ **[Platform](https://github.com/digitaldemocracy-app/platform)** — the code, a single open-source repository. Phase 1: foundations.

Everything is visible. Nothing is erased in silence. We are not a party, we have no candidates, and every source of money is published before it is used — see [NEUTRALITY](https://github.com/digitaldemocracy-app/manifesto/blob/main/NEUTRALITY.md).

Website: [digitaldemocracy.app](https://digitaldemocracy.app)
